# 테스트 및 평가

## 기능 테스트

- GPU 인식
- 모델 로딩
- text-to-image 생성
- img2img 생성
- 잘못된 파라미터 거부
- 이미지·메타데이터 저장
- LoRA 로딩

## 품질 평가

프롬프트 반영성, 이미지 품질, 해상도, 구도 안정성, seed 재현성, img2img 원본 보존 정도, LoRA 일반화 정도를 평가한다.

## 성능 기록

모델 로딩 시간, 이미지 1장 생성 시간, peak VRAM, 출력 파일 크기, 오류율을 기록한다.

## 완료 조건

기본 생성 3회 이상, seed 비교, steps·CFG 비교, strength 비교, LoRA 전후 비교 결과가 저장되어야 한다.
